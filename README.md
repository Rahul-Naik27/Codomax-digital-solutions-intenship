# Codomax Digital Solutions – Full Stack Web Development Internship
A full-stack blog application built during my 14-day Full Stack Web Development Internship at Codomax Digital Solutions. Features a complete CRUD blog system with search, filtering, likes, and a modern responsive UI.

## 🚀 Live Demo
- **Live Site (GitHub Pages, static):** https://rahul-naik27.github.io/Codomax-digital-solutions-intenship/
- **Note:** GitHub Pages hosts the static frontend only. To use the full dynamic features (add/edit/delete blogs), run the Express backend locally (see instructions below).

## 📌 About the Internship
- **Role:** Full Stack Web Development Intern
- **Duration:** 14 Days | Remote
- **Company:** Codomax Digital Solutions

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (custom design system, glassmorphism), Vanilla JavaScript
- **Backend:** Node.js, Express.js
- **Tools:** Git, GitHub, Postman, VS Code

## ✨ Features
- Full CRUD blog system (Create, Read, Update, Delete) via REST API
- Live search and category filtering
- Like/engagement system
- Read modal for full article view
- Form validation (client-side)
- Responsive design with animations and transitions
- Toast notifications for user feedback

## 🚀 Getting Started (Run Locally)

```bash
# Clone the repository
git clone https://github.com/Rahul-Naik27/Codomax-digital-solutions-intenship.git
cd Codomax-digital-solutions-intenship

# Install dependencies
npm install

# Start the server
node server.js
```
Then open `http://localhost:3000` in your browser.
